About Ludash

Ludash is a lightweight, self-hosted Linux update dashboard that provides a web-based interface for monitoring and managing system updates. It runs as a Docker container and can be easily integrated into existing Docker-based infrastructures.

  • Provides a central web interface for Linux update management.
  • Runs self-hosted using Docker.
  • Stores application data persistently using Docker volumes.
  • Can be deployed on an existing Docker network.
  • Supports direct access or deployment behind a reverse proxy.
  • Uses an encryption key to protect sensitive application data.
