Databasus Installation Script

The provided script sets up a self-hosted Databasus instance inside an existing Docker network named produktiv.

  • Checks if the script is executed with root privileges or via sudo.
  • Creates a persistent Docker volume named databasus mounted to /databasus-data.
  • Downloads the latest Databasus Docker image.
  • Creates and starts a container named databasus inside the produktiv network.
  • Configures the container to automatically restart using restart: always.
  • Uses databasus as the container hostname.
  • Displays the required reverse proxy configuration after successful installation.

About Databasus

Databasus is a self-hosted database backup management solution designed to simplify the creation and management of database backups. It runs as a Docker container and provides a web-based interface for managing backup configurations.

  • Runs completely self-hosted using Docker.
  • Provides a web-based management interface.
  • Stores its application data persistently in the Docker volume databasus.
  • Can be connected to databases running inside Docker networks or reachable through the configured network infrastructure.
  • Uses the hostname databasus within the produktiv Docker network.
  • The web interface is available internally on TCP port 4005.
  • Can be published externally through a reverse proxy such as Nginx Proxy Manager or Zoraxy.

Reverse Proxy

After the installation has completed, a reverse proxy entry must be created to access the Databasus web interface.

  • Hostname: databasus
  • Port: 4005
  • Protocol: TCP
  • Docker network: produktiv
